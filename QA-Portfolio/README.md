# QA Automation Portfolio

Two full-stack portfolio projects built to demonstrate complementary QA skills.

## 1. E-Commerce UI Automation
**Frontend:** HTML/CSS/JavaScript · **Backend:** Java/Spring Boot · **Database:** MySQL · **Tests:** Selenium, TestNG, Maven · **CI example:** Jenkins

- Browser UI for product search, cart, and simulated checkout
- Selenium smoke tests for page rendering, search, and checkout validation
- MySQL schema, Docker Compose configuration, and evidence checklist

[Open E-Commerce Automation project](./Ecommerce-Automation/README.md)

## 2. Online Bookstore API Testing
**Frontend:** HTML/CSS/JavaScript · **Backend:** Java/Spring Boot REST API · **Database:** MySQL · **Tests:** Postman, Newman, REST Assured · **CI:** GitHub Actions

- Book catalog UI and REST CRUD endpoints
- Postman collection with positive and negative cases
- REST Assured tests and SQL validation guidance
- OpenAPI/Swagger UI and CI workflow

[Open Online Bookstore API project](./Online-Bookstore-API/README.md)

## Evidence policy
The repository includes test scripts, report configuration, and evidence checklists. Run the projects and save actual screenshots/reports before describing them as executed results. Do not invent pass counts, defect totals, performance improvements, or screenshots.
