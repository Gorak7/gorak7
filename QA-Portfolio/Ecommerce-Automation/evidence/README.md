# Test Evidence

1. Homepage and product grid
2. Search results after searching for "Mouse"
3. Cart with item and calculated total
4. Empty-cart validation message
5. Checkout response with simulated order reference
6. Maven/TestNG report and CI build output
7. SQL query output confirming products in MySQL

Example SQL:
```sql
SELECT id, name, price, stock FROM products;
```

Keep personal data and secrets out of screenshots. Do not upload passwords, tokens, payment details, or real customer data. Never create mock screenshots and label them as executed test evidence.
