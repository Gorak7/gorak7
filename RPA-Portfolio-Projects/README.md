# RPA Automation & Production Support Portfolio

Two integrated demonstration projects:

1. [Invoice Processing Bot — Automation Anywhere A360](../RPA-Invoice-Processing-Bot/)
2. [Bot Monitoring & Failure Alert Tool — Python](../Bot-Monitoring-Failure-Alert-Tool/)

The first project processes invoice records and emits structured execution logs. The second consumes those logs, categorizes failures, stores incidents, and generates reports. All included datasets are synthetic. See each project README for setup and evidence requirements.

Dashboard: [FlowOps Operations Console (Lovable editor)](https://lovable.dev/projects/18544cd7-df22-4cc5-af5d-297389a8f1b2). A Lovable project shell exists; its AI build is waiting for workspace credits. A runnable Streamlit monitoring dashboard is included in Project 2.
