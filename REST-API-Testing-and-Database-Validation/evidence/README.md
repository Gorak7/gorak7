# Evidence Folder

Store evidence only after executing the project locally.

Suggested files:
- `postman-collection-run.png` — Collection Runner summary.
- `postman-get-post-1.png` — GET response, status, and assertions.
- `postman-post-create.png` — POST response and assertions.
- `sqlite-validation-output.png` — SQL query results.
- `execution-log.md` — actual test outcomes, date, and environment.

Do not upload secrets, authorization tokens, private URLs, or real personal data. No screenshots or test-pass claims are included by default; add genuine evidence from your own run.
