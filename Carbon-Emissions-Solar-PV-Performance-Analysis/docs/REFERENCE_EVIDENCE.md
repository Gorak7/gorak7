# Project reference

**Reference repository:** [PV Performance Analysis — jasonjowtien](https://github.com/jasonjowtien/PV_Performance_Analysis)

This repository was selected as the closest reference for the solar PV performance part of this project, including analysis of solar generation and performance indicators.

It was consulted for project understanding and analytical context. The implementation in this repository is independently developed and includes its own synthetic energy-demand and solar-generation data, onsite solar-use calculations, grid-emissions estimates and sustainability KPIs. No source code, dataset, screenshots or reported results are presented as our own.

**Our implementation:** [Carbon Emissions & Solar PV Performance Analysis](https://github.com/Gorak7/gorak7/tree/main/Carbon-Emissions-Solar-PV-Performance-Analysis)

**Data note:** The project uses synthetic demonstration data and an illustrative emissions factor. Its estimates are not a verified greenhouse-gas inventory or real-world facility measurements.
