# Project reference

**Reference repository:** [Energy Consumption Forecasting & Anomaly Detection — GlawinAlva24](https://github.com/GlawinAlva24/Energy-Consumption-Forecasting-Anomaly-Detection)

This repository was selected as the closest reference because it covers the same core problem area: energy consumption forecasting and anomaly detection.

It was consulted for project understanding and comparison of possible analytical approaches. The implementation in this repository is independently developed using its own synthetic dataset, Python analysis pipeline, forecasting baselines and anomaly-detection logic. No source code, dataset, screenshots or reported results are presented as our own.

**Our implementation:** [Energy Consumption Forecasting & Anomaly Detection](https://github.com/Gorak7/gorak7/tree/main/Energy-Consumption-Forecasting-Anomaly-Detection)

**Data note:** The project uses synthetic demonstration data. Its outputs are intended to demonstrate the analysis workflow, not to represent readings from a real facility.
