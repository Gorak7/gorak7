# Energy Analysis Results

This folder contains outputs generated by this repository's own Python pipeline.

## Reproduce

From this project directory:

```bash
pip install -r requirements.txt
python src/generate_data.py
python src/analyze_energy.py
python src/export_results.py
```

Or open the repository's **Actions → Generate Energy Analysis Results → Run workflow**. The workflow runs the same scripts and commits refreshed files in this folder.

## Files

| File | Description |
|---|---|
| `forecast_metrics.csv` | MAE, RMSE, and MAPE for each site and forecasting baseline on chronological holdout data. |
| `forecast_test_results.csv` | Actual and predicted electricity readings for each site, date, and baseline. |
| `anomaly_flags.csv` | Reading-level robust anomaly flags and baseline scores for electricity and water. |
| `anomaly_summary.csv` | Flagged-reading counts and rates grouped by site and metric. |
| `data_quality_report.csv` | Input, retained, rejected, duplicate, missing, invalid-date, and non-positive row counts. |
| `daily_consumption.png` | Portfolio daily electricity consumption trend. |
| `anomalies_by_site.png` | Site-level electricity trend with flagged readings. |
| `forecast_comparison_by_site.png` | Actual versus both forecast baselines for each site's holdout period. |

## Important interpretation notes

- All records are **synthetic demonstration data** generated with a fixed random seed. They are not real customer, building, or utility-meter readings.
- Forecast scores describe this synthetic chronological holdout only. They are not evidence of production forecasting performance.
- Anomaly flags are review candidates, not proof of equipment failure, waste, or fraud.
- The anomaly threshold is an absolute robust z-score of 3.5 after a 14-observation minimum rolling history. Forecasts compare a 7-day seasonal-naive baseline with a 7-day trailing mean.
- Metrics are calculated by site. MAPE excludes zero actual values; MAE and RMSE are in kWh.

These results are independently generated from the code in this project. The external repository listed in `../docs/REFERENCE_EVIDENCE.md` is credited as a learning/reference source; its results, screenshots, and data are not reused here.
