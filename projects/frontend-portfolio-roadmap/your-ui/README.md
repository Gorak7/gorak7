# your-ui — Accessible React Component Library

A TypeScript-first component library and interactive playground following the roadmap.

## Stack
React 18, TypeScript strict mode, Vite, CSS custom properties, Vitest, React Testing Library, user-event, axe and Storybook.

## Run
```bash
npm install
npm run dev
npm test
npm run build
```

## Component roadmap
Button, TextField, Checkbox, Switch, VisuallyHidden, Dialog, Tabs, Tooltip, Popover, Combobox, Toast and DataTable. The initial playground demonstrates Button, TextField, Dialog and keyboard-operable Tabs.

## Accessibility checklist
- Accessible names and visible focus
- Dialog Escape handling and focus return
- Tabs support arrow keys, Home and End
- Reduced-motion and light/dark preferences
- Automated axe checks plus manual keyboard and screen-reader audits

Do not claim WCAG conformance or zero violations until the complete automated and manual audit has been performed.
