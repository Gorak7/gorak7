# Execution notes

Record Python, browser, Playwright, Selenium, Appium server, UiAutomator2 and emulator versions for each run.

Defect report template: ID, title, environment, preconditions, steps, expected, actual, severity, priority, screenshots and logs.

Known constraints: mock service uses in-memory state and demo credentials; do not deploy it as a real IoT control plane. External demo sites may change and mobile tests require a local emulator.
