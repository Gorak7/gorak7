# GRC Analyst Portfolio

Two fictional case studies demonstrating GRC workflows.

1. **Mini Compliance Program – ISO 27001:2022**: 15-control sample, asset inventory, gap plan and management summary. All controls are marked planned/not evidenced because no internal company artifacts were supplied.
2. **Third-Party Vendor Risk Assessment – Google Workspace**: 25-question public-source desktop review; 19 preliminary assessments and 6 Not Reviewed. Provisional HIGH / evidence follow-up required; defer final approval until current assurance reports, contract/DPA, subprocessors and tenant configuration are reviewed.

**Integrity:** These are a fictional tabletop exercise and public-source desktop review, not independent audits, certification, penetration tests or actual procurement approval. See each folder for methods and limitations.
