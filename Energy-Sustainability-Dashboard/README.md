# Energy & Sustainability Insights Dashboard

A Lovable project was scaffolded for a combined dashboard covering the Carbon Emissions & Solar PV Performance Analysis and Energy Consumption Forecasting & Anomaly Detection projects.

- Lovable project: https://lovable.dev/projects/3d991bdd-3b9c-4f3b-a262-f8b5c6a27147
- Intended preview: https://id-preview--3d991bdd-3b9c-4f3b-a262-f8b5c6a27147.lovable.app

**Status:** Project scaffold created. The dashboard implementation has not yet completed because the Lovable workspace is out of credits. Do not present the preview as a finished dashboard until the build is completed and checked.

The dashboard specification calls for client-side CSV uploads, validation, interactive sustainability and forecasting charts, anomaly exploration, data-quality reporting, and a references page. It must label built-in sample values as illustrative demo data and must not invent measured results.
